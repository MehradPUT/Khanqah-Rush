# Khanqah Rush

Telegram Game arcade game (lumberjack-style woodchopping with Persian characters).

This is a fork for contribution upstream. See [Contributing](#contributing) for the fork workflow.

## Stack

- Vite 5 + TypeScript 5 (`strict`)
- Telegram Games platform (client still on `telegram-web-app.js`; migrating
  to `games.js` + `TelegramGameProxy.shareScore()` is tracked future work)
- `telegraf` (bot sample only)
- Vanilla Canvas, no React/Vue

## Getting started

```bash
npm install
cp .env.example .env   # reserved for future bot/server work
npm run dev            # vite on http://localhost:5173
npm run build          # tsc + vite build -> dist/ (gitignored)
npm run preview
npm test               # vitest run
npm run lint           # biome check
npm run format         # biome format --write
npm run wasm:build     # rebuild the Rust signer stub (needs the wasm32 target)
npm run deploy         # build + deploy dist/ to Cloudflare Workers
```

Rust prerequisite for the signer (one time):
`rustup target add wasm32-unknown-unknown`. Without it, `wasm:build`
warns and skips — the game runs without the stub.

## Layout

```
index.html                  # Vite entry -> /src/main.ts (TS game shell)
src/
  main.ts                   # Vite TS entry (expects canvas#gameCanvas)
  engine/Game.ts            # game loop, pillars, particles
  characters/               # nima, fargol, ali, amirhossein, ahmad, erfan, fateme, parsa
  telegram/tma.ts           # TmaBridge
  audio/                    # SoundEngine, VoiceEngine (see PROJECT_RULES.md)
  styles/game.css
  wasm/signer.ts            # loader for the Rust signer stub (optional)
  vite-env.d.ts
wasm/signer/                # Rust signer stub -> public/wasm/signer.wasm
scripts/build-wasm.mjs      # cargo build + copy (tolerant without Rust)
wrangler.toml               # Cloudflare Workers static hosting for dist/
public/                     # served as-is by Vite
  images/, sounds/hit1-3.mp3, fonts/ (unused by the procedural TS game; kept for future use)
tests/                      # smoke + wasm-loader suites
docs/
  anticheat-future.md       # plan for WASM-signed score requests (own PR)
  DEPLOYMENT.md             # complete Games deploy walkthrough (BotFather, Workers)
PROJECT_RULES.md            # strict sound policy - read before adding audio
```

> Note: the game entry is the Vite TS app (`/src/main.ts`, fully procedural
> canvas + WebAudio, no asset files). The legacy character carousel and
> leaderboard table have no TS counterpart yet (game plays as Nima) and will
> return in later tasks.

Ignored but kept locally: `node_modules/`, `dist/`, `scratch/` (see `.gitignore`).
`scratch/` is local one-off sprite/tooling output, `dist/` is regenerated by `npm run build`.

To ship the game, follow [`docs/DEPLOYMENT.md`](docs/DEPLOYMENT.md) end to end
(Cloudflare Workers hosting + BotFather bot/Game registration).

## Sound policy

Strict, per `PROJECT_RULES.md`:

- No custom per-character SFX, voice engines, or TTS.
- Only native `hit1`/`hit2`/`hit3`.
- Character abilities are visual only: combat popups, HUD gauges, sprites, haptics.

## Tests

- `tests/smoke.test.js` (vitest) - repo invariants (scripts, entry wiring, docs).
- `tests/wasm-signer.test.js` (vitest) - signer loader graceful degradation
  plus a real-stub round trip when `public/wasm/signer.wasm` is built.
- No anti-cheat coverage right now: the client honeypot was removed (it can't
  stop forged requests). See `docs/anticheat-future.md` for the planned
  WASM-signed replacement (separate branch/PR).

## Contributing

1. Add upstream once: `git remote add upstream <friend-original-url>`
2. Branch from `main`: `git checkout -b feat/...`
3. Run `npm test`, `npm run lint`, `npx tsc --noEmit` before pushing.
   (CI in `.github/workflows/ci.yml` runs check, test, lint, and build
   on every push and PR.)
4. Install pre-commit: `pip install pre-commit && pre-commit install`
5. Open PR against upstream `main`, describe testing.

No `LICENSE` file yet - confirm with upstream before publishing.
